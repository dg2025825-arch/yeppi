# 데이터 출처

**파일:** dailyActivity_merged.csv, sleepDay_merged.csv (전처리된 사본)

**출처(1차):** Fitbit Fitness Tracker Data (arashnic), Kaggle, `Fitabase Data 4.12.16-5.12.16` 폴더, 접근. https://www.kaggle.com/datasets/arashnic/fitbit/versions/1?resource=download&select=Fitabase+Data+4.12.16-5.12.16

**원출처:** Zenodo https://zenodo.org/record/53894 (Kaggle Provenance의 Sources 항목). 저자·연도: [Zenodo 페이지에서 확인 후 기재]. Kaggle의 Collection Methodology는 "preprocessed"입니다.

**이용 조건:** [Kaggle License 항목을 그대로 기재]. 공식 대회에 출품할 때는 Zenodo 원본의 이용 조건도 확인해야 합니다.

**내용:** 2016-04-12 ~ 2016-05-12 동안 Fitbit 기기를 착용한 사용자의 하루 단위 활동 기록과 수면 기록입니다. 사용자는 숫자 Id로만 구분되며 이름·연락처·주소는 없습니다. 활동 파일 33명, 수면 파일 24명입니다.

**크기:** dailyActivity_merged.csv 864행·15열, sleepDay_merged.csv 약 411행 5열

## 열 설명

### dailyActivity_merged.csv

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| Id | 사용자 번호(익명) | 사용자 단위 분할, 결과물에는 A, B로 표기 |
| ActivityDate | 활동 날짜(월/일/연) | 전날 활동 → 다음 날 수면 연결 |
| TotalSteps | 하루 걸음 수 | 입력 변수 |
| TotalDistance, TrackerDistance, LoggedActivitiesDistance | 이동 거리(단위 설명 없음) | 사용하지 않음 |
| VeryActiveDistance, ModeratelyActiveDistance, LightActiveDistance, SedentaryActiveDistance | 강도별 이동 거리 | 사용하지 않음 |
| VeryActiveMinutes | 고강도 활동 시간(분) | 입력 변수 |
| FairlyActiveMinutes | 중강도 활동 시간(분) | 입력 변수 |
| LightlyActiveMinutes | 저강도 활동 시간(분) | 입력 변수 |
| SedentaryMinutes | 좌식 시간(분) | 입력 변수 |
| Calories | 소모 칼로리(기기 추정값) | 사용하지 않음 |

### sleepDay_merged.csv

| 열 | 뜻 | 이 프로젝트에서 |
|---|---|---|
| Id | 사용자 번호(익명) | 활동 파일과 연결 |
| SleepDay | 수면 날짜(시각은 모두 12:00:00 AM) | 날짜로 변환해 연결 |
| TotalSleepRecords | 그날의 수면 기록 개수(1~3) | 확인용 |
| TotalMinutesAsleep | 실제로 잔 시간(분) | 정답(수면 부족) 기준 |
| TotalTimeInBed | 침대에 누워 있던 시간(분) | 사용하지 않음 |

## 전처리된 파일에서 확인한 점

- 걸음은 있지만 활동 0분·좌식 1440분인 날이 남아 있음 (예: 8583815059의 5/2~5/4) → 기기 미착용 의심, 삭제 완료
- 하루 기록이 짧은 날이 있음 (활동 4종 합이 1440분보다 많이 작음) → 기준 정해 검토
- 수면 58~137분의 짧은 기록(낮잠·부분 기록 추정)이 있음
- 1844505072의 TotalTimeInBed가 세 번 모두 961 → 유지
- 사용자별 수면 기록 일수가 2~3일에서 약 30일까지 다름
- 활동 파일은 걸음 0인 날이 빠져서, 날짜가 연속되지 않는 사용자가 있음 → 전날 활동 연결 시 행이 줄어듦
