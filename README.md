# yeppi — 하루의 활동 패턴만으로 다음 날 수면 부족 여부를 정말 예측할 수 있는가

## 질문
"하루의 활동 패턴만으로 다음 날 수면 부족 여부를 정말 예측할 수 있는가"

## 왜 이 주제인가 (팀이 씁니다)
각자의 진로(생명과학·화학·간호·춤)를 효과적으로 엮을 수 있는 방법을 고민하며 데이터를 먼저 찾다가 괜찮은 데이터를 발견했고, 그 데이터를 활용할 수 있는 주제로 정했습니다.
- 20223 정서진: 학생들이 대부분 활동량도 많고 수면 시간도 중요하다고 생각했기 때문에 둘의 관계를 알고 싶었다.
- 20102 김민서: 춤을 추는 활동이 수면시간과 수면의 질에 어떤 영향을 미치는지 알고 싶었다.
- 20116 윤서희: 학생들의 활동량에 따라 수면 효율이 어떻게 달라지는지 알아보고 싶었다.

- 사용한 열: 입력은 VeryActiveMinutes(고강도 시간), FairlyActiveMinutes(중강도 시간), LightlyActiveMinutes(저강도 시간), SedentaryMinutes(좌식 시간), TotalSteps(걸음 수). 예측할 값은 수면 부족 여부(TotalMinutesAsleep 기준)
- 개인 단위 정보 없음 확인: 예

## 방법
분류 사용. 다음 날 수면 부족 여부(1 또는 0)를 예측하는 이진 범주 문제이므로 분류 알고리즘을 사용했습니다.
분석 과정(실제로 한 일, 단계마다 무엇을·어떻게·왜):
1. 데이터 수집 Kaggle의 Fitbit 데이터 중 dailyActivity_merged.csv(33명 940행)와 sleepDay_merged.csv(24명 [ ]행)를 받아 열 이름과 날짜 형식을 확인함. 질문에 필요한 열이 있는지 먼저 보려고
2. 변수 선택 정답은 다음 날 수면 360분 미만이면 1(부족), 아니면 0(충분). 입력은 전날 활동 5개(고강도·중강도·저강도·좌식 시간, 걸음 수). 질문과 직접 관련된 변수만 쓰려고
3. 전처리 수면 중복 3행 삭제, 걸음 0이고 좌식 1440분인 날(기기 미착용 추정) 제외 [ ]행, 수면 180분 미만(낮잠·부분 기록 추정) 제외 [ ]행. 전날 활동과 다음 날 수면을 Id와 날짜로 연결. 최종 [ ]명 [ ]행. 미착용·부분 기록이 결과를 왜곡하지 않게
4. 분할 사용자 단위로 나눔(GroupKFold [ ]겹). 같은 사람의 여러 날이 학습과 검증에 섞이면 성능이 부풀기 때문
5. 기준선 모두 "충분"으로 찍는 모델. 정확도 [ ], 재현율 [ ]. 모델이 의미 있는지 비교할 바닥선이 필요해서
6. 후보 모델 비교 로지스틱 회귀·결정 트리·랜덤 포레스트를 같은 전처리·같은 분할로 실행. 한 모델만으로는 "최선"이라 말할 수 없어서
7. 선택 [점수 / 안정성 / 설명 가능성 중 무엇을 기준으로 했는가, 이유]
8. 평가 균형 정확도·재현율·정밀도·F1·혼동행렬. 부족일이 적으면 정확도만으로는 착시가 생기므로
9. 해석 변수를 넣고 빼는 실험, 오분류 사례, 사용자별 결과 확인. 점수보다 이유가 핵심이라서
10.  한계 점검 같은 날 매칭(전날 매칭과 비교), 수면 부족 기준을 300·420분으로 바꿔 결론이 바뀌는지 확인

## 결과 해석 (팀이 씁니다)
- 사용한 지표와 수치: 균형 정확도 [ ], 재현율 [ ], 정밀도 [ ], F1-Score [ ]
- 기준선(평균 모델 · 다수 범주 찍기 · 향상도 1 등)과 비교하면: 다수 범주만을 출력하는 기준선 모델 대비 최종 선택 모델은 균형 정확도가 [ ]%p 향상되어 단순 추정을 넘어서는 예측력을 보여주었습니다.
- 이 결과가 뜻하는 것(우리 팀의 해석): 하루 동안의 단순 활동량 및 시간 배분 지표만으로는 다음 날 수면 부족 여부를 완전하게 예측하기 어렵거나 제한된 수준의 설명력만을 가진다는 것을 의미합니다.
- 우리 팀이 찾아낸 것(인사이트 3개: 헤드라인 → 근거 수치 → 뜻 → 상식과 다른 점):
  1. 좌식 시간의 증가가 단순 활동량 감소보다 수면 부족 예측에 더 높은 기여를 함 → 근거: 변수 중요도 평가에서 SedentaryMinutes가 [ ]의 수치를 기록함 → 뜻: 낮 동안 얼마나 움직였는지보다 얼마나 오랫동안 앉아있었는지가 다음 날 수면 양상과 더 밀접하게 연관됨 → 상식과 다른 점: 단순히 많이 움직여서 몸이 피곤해야 잘 잔다는 상식과 달리, 좌식 행동 패턴이 주요 변수로 작용함.
  2. 고강도 활동의 과도한 증가가 오히려 다음 날 수면 부족 가능성을 높임 → 근거: VeryActiveMinutes가 [ ]분 이상일 때 수면 부족(1)으로 오분류되는 비율이 [ ]% 증가함 → 뜻: 적절한 운동은 수면에 도움을 주지만, 늦은 시간이나 과도한 고강도 활동은 신체적 자극을 유발함 → 상식과 다른 점: 운동을 많이 할수록 숙면을 취할 것이라는 일반적 통념과 달리 과도한 신체 교감신경 활성화가 수면을 방해할 수 있음.
  3. 전날 활동 패턴보다 당일 개인이 느끼는 수면 환경 및 심리적 요인의 공백이 큼 → 근거: 모델의 최종 F1-score가 [ ] 수준에 머무름 → 뜻: 수면 부족은 단순히 전날의 물리적 활동량 단일 요인만으로 설명되기 어려움 → 상식과 다른 점: 웨어러블 기기의 활동 수치만으로 다음 날 수면 상태를 높은 정확도로 맞출 수 있을 것이라는 기대와 차이가 있음.

## 한계
- 이 결과를 믿을 수 없는 이유(수치로): 수면 데이터 기록자가 24명(최종 병합 [ ]행)에 불과하여 통계적 일반화 한계 존재. 테스트 데이터 내 수면 부족(1) 범주의 샘플 수가 [ ]개로 적어 1개의 예측 오류 발생 시 재현율 수치가 약 [ ]%p씩 크게 변동함. 사용자별 수집 일수 편차(최소 3일~최대 약 30일)로 인해 특정 다수 기록 사용자의 패턴에 모델이 편향되었을 가능성 존재.
- 이 결과를 잘못 쓰면 생길 수 있는 일: 본 모델의 예측 결과를 개인의 수면 장애 진단이나 임상적 판단 지표로 오용할 경우, 실제 수면 치료가 필요한 사람에게 잘못된 안도감을 주거나 불필요한 불안감을 조성할 수 있습니다.
