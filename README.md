# yeppi: 하루의 활동 패턴만으로 다음 날 수면 부족 여부를 정말 예측할 수 있는가

## 팀원
- 20223 정서진 / 20102 김민서 / 20116 윤서희

## 질문
"하루의 활동 패턴만으로 다음 날 수면 부족 여부를 정말 예측할 수 있는가"

**처음 가설:** 하루 활동 패턴만으로는 다음 날 수면 부족 여부를 예측할수 없을 것이다.

## 왜 이 주제인가
각자의 진로(생명과학·화학·간호·춤)를 효과적으로 엮을 수 있는 방법을 고민하며 데이터를 먼저 찾다가 괜찮은 데이터를 발견했고, 그 데이터를 활용할 수 있는 주제로 정했습니다.

- 20223 정서진: 학생들이 대부분 활동량도 많고 수면 시간도 중요하다고 생각했기 때문에 둘의 관계를 알고 싶었다.
- 20102 김민서: 춤을 추려면 인체에 대해 잘 알아야 하니까!!!!!!!!!!!
- 20116 윤서희: 학생들의 활동량에 따라 수면 효율이 어떻게 달라지는지 알아보고 싶었다.

## 데이터
- 출처: Fitbit Fitness Tracker Data (arashnic), Kaggle, `Fitabase Data 4.12.16-5.12.16` 폴더, [접근일] 접근. https://www.kaggle.com/datasets/arashnic/fitbit/versions/1?resource=download&select=Fitabase+Data+4.12.16-5.12.16
- 원출처: https://zenodo.org/record/53894#.X9oeh3Uzaao
- 이용 조건: CC0: Public Domain
- 사용 파일: `dailyActivity_merged.csv`, `sleepDay_merged.csv` + [추가 사용 시: hourlyIntensities, heartrate_seconds, minuteSleep]
- 기간·행 수·열 수: 2016-04-12 ~ 2016-05-12 · 활동 33명 940행 15열 / 수면 24명 [ ]행 5열 / 병합 후 [ ]명 [ ]행
- 사용한 열: 입력은 VeryActiveMinutes(고강도 시간), FairlyActiveMinutes(중강도 시간), LightlyActiveMinutes(저강도 시간), SedentaryMinutes(좌식 시간), TotalSteps(걸음 수). 예측할 값은 수면 부족 여부(TotalMinutesAsleep 기준) 또는 수면 효율(TotalMinutesAsleep ÷ TotalTimeInBed)
- 개인 단위 정보 없음 확인: 없음.

**선정 이유:** 인체 관련 데이터를 찾다가 발견했습니다. 활동 강도와 수면 시간이 같은 사람·같은 날짜로 연결된다는 점이 우리 질문에 맞다고 판단했습니다.

## 방법
1. 데이터 수집	Kaggle의 Fitbit 데이터 중 dailyActivity_merged.csv(33명 940행)와 sleepDay_merged.csv(24명 [ ]행)를 받아 열 이름과 날짜 형식을 확인함. 질문에 필요한 열이 있는지 먼저 보려고
2. 변수 선택	정답은 다음 날 수면 [360]분 미만이면 1(부족), 아니면 0(충분). 입력은 전날 활동 5개(고강도·중강도·저강도·좌식 시간, 걸음 수). 질문과 직접 관련된 변수만 쓰려고
3. 전처리	수면 중복 3행 삭제, 걸음 0이고 좌식 1440분인 날(기기 미착용 추정) 제외 [ ]행, 수면 [180]분 미만(낮잠·부분 기록 추정) 제외 [ ]행. 전날 활동과 다음 날 수면을 Id와 날짜로 연결. 최종 [ ]명 [ ]행. 미착용·부분 기록이 결과를 왜곡하지 않게
4. 분할	사용자 단위로 나눔(GroupKFold [ ]겹). 같은 사람의 여러 날이 학습과 검증에 섞이면 성능이 부풀기 때문
5. 기준선	모두 "충분"으로 찍는 모델. 정확도 [ ], 재현율 [ ]. 모델이 의미 있는지 비교할 바닥선이 필요해서
6. 후보 모델 비교	로지스틱 회귀·결정 트리·랜덤 포레스트를 같은 전처리·같은 분할로 실행. 한 모델만으로는 "최선"이라 말할 수 없어서
7. 선택	[점수 / 안정성 / 설명 가능성 중 무엇을 기준으로 했는가, 이유]
8. 평가	균형 정확도·재현율·정밀도·F1·혼동행렬. 부족일이 적으면 정확도만으로는 착시가 생기므로
9. 해석	변수를 넣고 빼는 실험, 오분류 사례, 사용자별 결과 확인. 점수보다 이유가 핵심이라서
10. 한계 점검	같은 날 매칭(전날 매칭과 비교), 수면 부족 기준을 [300·420]분으로 바꿔 결론이 바뀌는지 확인

**수면 부족 기준:** 수면 [360]분 미만. 연구자가 정한 값이며 임상 진단이 아닙니다. 이 기준을 택한 이유: [직접 작성]
